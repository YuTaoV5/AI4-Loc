# 资料来源与事实口径

资料核对时间：2026-09-26。链接用于回溯，网页可能继续更新。

## A. 官方：模型定位、API、限制

1. TypeSafe 发布文，2026-09-15：\
   https://typesafe.ai/blog/introducing-system-one-models-and-jev\
   用于 Jev / System One 定位、官方工作流评测、官方性能价格数字及发布方自己披露的评测限制。193.6× / 444.6× 是官网展示的最高倍数，发布文指出其接近工作流中的高端收益。

2. Quickstart：\
   https://docs.typesafe.ai/introduction/quickstart\
   用于 Playground、HTTP endpoint、Python SDK、state/questions/answers 请求响应示例。

3. System One：\
   https://docs.typesafe.ai/concepts/system-one\
   用于类型化决策输出与生成式 LLM 的产品边界；官方明确校准是跨样本统计属性，不保证每个答案正确。

4. API Reference：\
   https://docs.typesafe.ai/api\
   用于 Choice / Score / Noul 的 schema、probabilities、confidence、usage 与错误码。

5. Models：\
   https://docs.typesafe.ai/models\
   用于模型 ID、价格、当前限额、上下文长度、输入类型、语言支持、数据处理声明。限流可能动态调整。

6. Confidence：\
   https://docs.typesafe.ai/confidence\
   用于 confidence 的官方语义及根据风险设置路由阈值的建议。

7. Jev 1.13 Jaggedness：\
   https://docs.typesafe.ai/model-jaggedness/jev-1.13\
   用于字面理解、数学 / 计数 / 日期、间接推理、长 state、对抗文本和指令/标准不一致等官方已知弱点。页面最后审阅时间标为 2026-09-17。

8. Score：\
   https://docs.typesafe.ai/primitives/score\
   用于 Score 的概率加权位置语义、等级定义实践、多个 Score 在代码中归一化组合。

## C. GitHub 独立评测与反例

12. ickma2311/jev-baselines-eval：\
    https://github.com/ickma2311/jev-baselines-eval\
    Banking77 / CLINC150 预注册评测。Banking77 表格数据用于比较 Jev、GPT-5.6 Terra 与监督 encoder。README 同时公开了错误区间与协议限制。

13. statsguysam/jev-classification-benchmark：\
    https://github.com/statsguysam/jev-classification-benchmark\
    TREC 200 条样本中，GPT-6 Astra few-shot 的 Jev review 前后变化作为误改案例。仓库将这批结果说明为探索性研究，样本和数据划分有限。

14. zhlei07/open-system-one：\
    https://github.com/zhlei07/open-system-one\
    独立 CPU-only 对照工作。此版 deck 未引用其汇总数值，避免把特定硬件 / provider / 输入描述结果与手机 SoC 直接类比。

## D. 手机 SoC 软件工具链公开参考

15. Android VTS：\
    https://source.android.com/docs/core/tests/vts\
    说明通用 Android Vendor Test Suite 覆盖 Kernel 与 HAL，并在 host 上驱动设备测试。仅作公开流程参考，不代表华为内部工具。

16. VTS 系统测试：\
    https://source.android.com/docs/core/tests/vts/systems\
    VTS kernel / HAL 测试计划说明。

17. Perfetto 系统追踪：\
    https://perfetto.dev/docs/getting-started/system-tracing\
    说明 Android / Linux system trace 可聚合多进程、内核与系统数据源，并可用 PerfettoSQL 分析。

18. Perfetto CPU scheduling：\
    https://perfetto.dev/docs/data-sources/cpu-scheduling\
    说明调度事件可呈现线程运行 CPU、唤醒和阻塞相关信息。

19. Perfetto GPU：\
    https://perfetto.dev/docs/data-sources/gpu\
    说明可采集 GPU counters、render stages、内存跟踪和 GPU 日志；具体生产者依平台。

20. Perfetto CPU frequency / idle：\
    https://perfetto.dev/docs/data-sources/cpu-freq\
    说明可通过 ftrace 记录 CPU frequency 与 idle 事件，并存在平台限制。

## E. 口径约定

- 官方价格、功能和弱点以 TypeSafe 文档为准，且它们可能变更。
- 官方 workflow benchmark 标为“官方评测”，不当作第三方复现。
- GitHub 测量标为“独立评测”或“探索性反例”，保留样本数、测试集和配置限制。
- PaperDance 数值标为“案例作者自测”，不推广为一般模型能力或 SoC 实测。
- 华为 SoC 场景、流程和试点指标标为“本汇报推演 / 建议”，并非现有内部事实。
