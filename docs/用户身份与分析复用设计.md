# 首页、身份与分析复用

首页删除分析工作流卡片，内容限定在单屏中。桌面和窄屏均不产生页面纵向滚动；展开分析选项时使用可关闭的浮层，较长的选项仅在浮层内滚动。Benchmark 案例、摘要、筛选按钮采用统一蓝色文字和状态配色。

身份由服务端账号决定，页面不再显示视角切换器，也不允许注册时自行选择身份。新账号默认测试人员。管理员在左侧辅助导航的“账号管理”中设置测试人员、专家、领导或管理员身份；非管理员接口请求会被拒绝，最后一个管理员不能被降级。首次登录分别进入新建分析、专家中心、效能看板和账号管理。已有登录状态刷新保留当前页面，身份变化在下一次刷新中同步。

经验中心支持按名称、贡献者、团队、类别、匹配词和分析建议即时搜索，每次展示 12 张卡片，可以加载更多。所有经验都有右下角“阅读经验”按钮，投稿合入记录保留独立入口。

## 防重复机制

- 对同一账号的规范化日志（统一 CRLF/LF、忽略尾部空白）、所选 Skill 内容/版本/顺序、组合、源码条件、下载选项、Benchmark 数据和分析引擎计算条件指纹。
- 查找与创建指纹任务之间无异步间隔；并发相同请求共享同一任务。运行中共享状态和进度，完成后复用报告，不会再次执行分析。
- 记录重复提交次数、文件名称、机器批次与时间，避免重复任务淹没列表。响应明确返回 `reused`。
- 失败任务不复用；条件变化创建新任务。高级选项允许显式重新分析已完成结果，同条件运行中任务仍然合并。
- 不跨账号复用，业务任务和 Benchmark 试跑也相互隔离。近似故障仅按问题签名关联，不作为免分析依据。
- 老任务缺少完整条件指纹，因此升级后的首次相同提交会创建带指纹的新任务，后续才复用。

## 后续产品方向

1. 领导同时查看独立故障数和重复出现次数：分析省下了多少执行，以及故障是否在不同机器或批次复发，分别统计。
2. 专家经验增加类别筛选和“解决问题数 / 满意度 / Benchmark 成绩”排序；保留历史版本，便于归因能力变化。
3. 测试人员按批次汇总重复日志，默认展示代表性日志及差异；修复后验证应独立记录为验证任务，避免把旧报告当成新一轮验证结论。

验证：24 项自动测试，包括管理员边界、最后一个管理员保护、并发请求合并、完成结果复用、条件变化、显式重跑与账号隔离。浏览器检查首页尺寸、经验搜索、阅读按钮及账号管理。
