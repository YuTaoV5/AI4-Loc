# SGLang 并发决策与 KV 缓存实测

入口：[完整中文报告](../research/kv-concurrency-20261016/REPORT.md) / [离线网页版](../research/kv-concurrency-20261016/report.html)。

同一A100、同一Qwen3.8-27B、SGLang 0.5.21；覆盖1/4任务、1/8次同题干不同选项、冷/热条件、顺序/批量八题和观测成本对照。正式112个trial、980次HTTP、1330个内部问题评估，全部成功并唯一关联服务端轨迹。

实测单次Decision基本无速度优势；热条件8步时，1任务和4任务整批耗时分别减少11.57%与11.03%。没有明显内存节省，四任务八步时活跃KV几乎相同，Decision线性状态峰值反而更高。Decision不产生文本token，因此报告分别提供完整概率结果耗时和Chat真实首内容TTFT。

生产参数虽写4并发，实际被自动状态池限制为1。实验实例提高状态池并验证实际4并发，结束后恢复生产原配置。不能把实验参数误认为已经上线。

所有时间点的 [KV/状态池记录](../research/kv-concurrency-20261016/tables/scheduler-snapshots.csv)、[服务端排队与prefill](../research/kv-concurrency-20261016/tables/server-requests.csv)、[客户端响应/TTFT](../research/kv-concurrency-20261016/tables/calls.csv)、[NVML显存与功耗](../research/kv-concurrency-20261016/tables/gpu-samples.csv)、[协议和复现材料](../research/kv-concurrency-20261016/README.md)均已保留。启动区段校准独立归档，不混入正式结果；本轮不测定位准确率。
