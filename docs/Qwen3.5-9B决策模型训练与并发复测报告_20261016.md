# Qwen3.5-9B 决策模型训练与并发复测

完整规范、原始派生数据和科研图统一放在 [研究目录](../research/jev-qwen35-9b-20261016/README.md)，详细结果见 [实测报告](../research/jev-qwen35-9b-20261016/REPORT.md)。

服务器真实训练已完成：官方固定版本Qwen3.5-9B，LoRA训练参数5,308,416，396微步/99更新，CE预热后RLCD，开发集选择epoch1。训练后的权重在 `/root/gpufree-data/systemone/models/AI4Loc-Jev-Qwen3.5-9B`，逐文件指纹在研究目录。它是参考Laya方法的Qwen决策适配，不是从随机参数预训练9B，也不是TypeSafe Jev的私有架构复现。

两模型各完成112个性能trial、980正式HTTP、1330内部评分，并各有522个第一诊断分类请求。87案例多数投票从66/87提升到78/87，但仅为第一诊断弱监督口径。机制聚类置信区间触及零，开发集仅4例，不可据此断言跨项目显著提高。NLL由0.830升至1.724；开发温度0.5进一步使测试NLL升至1.957，当前不建议把该概率当作可靠因果置信度。

4任务×8步预热条件，训练后Decision整批1.2803秒、单token Chat整批1.3876秒，缩短7.74%；活跃KV峰值均值458.219/458.125MiB，linear状态槽16/13，没有显存节省证据。完整8条件、批量8题、冷/热、观测敏感性、排队/prefill及NVML功耗记录均可重算。不能将完整概率返回时间和Chat首内容时间混作相同语义的TTFT。

完整Agent先因8k上下文不足失败；32k检查又发现`tool_calls:null`解析错误。保留失败后，在全新目录对两模型使用相同兼容修复重跑，12次流程全部输出有效报告，各流程源码位置命中仍2/3；训练后混合流程三例总时间29.247秒，而基座混合流程为53.464秒，但纯Chat更快、仅3例且固定模型顺序，不能证明普遍闭环收益。详细调用、token、定界/定位/报告耗时及匿名沙箱检查见研究目录 `agent32k/`。

原生产27B服务已恢复，Decision/Chat真实合成响应内容验收通过，新模型未自动切生产。用户授权清理的11个PPLX可重下载分片已删除并保留恢复指纹；PPLX若需重启，先恢复固定版本分片。数据集、业务状态、生产27B权重和新训练权重保留。

公开仓库只含允许字段的统计、概率、时序、脚本和说明；原始日志、完整请求/SSE、训练适配器及完整Agent源码/工具轨迹在服务器和本地Git忽略归档，进程环境不在归档。3份归档逐文件SHA核对见研究目录的归档元数据与核验结果。
