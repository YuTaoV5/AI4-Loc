## 一条端到端开发路线

1. 定义首诊断家族与证据要求，提供真实审核的JSONL；按机制组划分，不能按同一日志的选项排列随机拆分。
2. 运行数据skill脚本，得到private/frozen/validation；检查缺类和人工审核结果。
3. 下载固定Qwen3.5-9B并逐文件验SHA，准备独立CUDA环境和足够显存、磁盘。
4. 默认仅生成训练计划；确认资源可用后显式`--execute`训练。参数和日志全部记录，不写旧run。
5. dev选epoch，导出合并模型；固定方案后才看test。另起相同预算CE-only用于方法比较。
6. 隔离SGLang实例启动，确认实际上下文、有效并发和状态池容量。
7. 合成API探针验收，再用独立test做3排列多数票；时间、token、HTTP、错误保留。

核心命令（完整参数解释与环境步骤见上表两份引用文档）：

```bash
python skills/ai4loc-decision-data/scripts/prepare_dataset.py \
  --input /data/annotations/reviewed.jsonl --output /data/runs/decision-new-001

python skills/ai4loc-decision-finetune/scripts/train.py \
  --project-root "$PWD" --run-dir /data/runs/decision-new-001 \
  --base /data/models/Qwen3.5-9B --output /data/models/AI4Loc-Qwen9B-new-001

# 上一条只生成计划。实际训练在同命令后添加 --execute。
# 服务启动按skill中的SGLang配置执行，再验收：
python skills/ai4loc-decision-finetune/scripts/probe.py \
  --base-url http://127.0.0.1:30003 --model AI4Loc-Qwen9B \
  --output /data/runs/decision-new-001/api-probe.json

python skills/ai4loc-decision-finetune/scripts/evaluate.py \
  --run-dir /data/runs/decision-new-001 --tokenizer /data/models/Qwen3.5-9B \
  --base-url http://127.0.0.1:30003 --model AI4Loc-Qwen9B \
  --output /data/runs/decision-new-001/eval-fixed-test
```

## 已验证配置提供哪些参考

- 9B训练：48处rank8/alpha16 LoRA，5,308,416个可训练参数；历史33例、3轮、每例4次候选构造产生396微步/99更新。学习率1e-4，累计4微步，BF16骨干/FP32适配器。
- GPU：历史A10080GB；torch训练allocated峰值18.74GiB。推理static0.55时NVML resident约47.5GiB。两类观测不可当同一显存需求。
- PPLX v1：BF16参数48.59GiB；CPU卸载历史均值19.455s、全GPU独立轮5.672s；同轮通用SGLang2.563s。输入和引擎条件见[实测报告](../research/pplx-timeshare-20261012/REPORT.md)。
- 效率：四任务×八步预热、单字母Chat基线下，27B整批3.634对4.085s，9B1.280对1.388s，每格5次。只作为该条件的服务性能参考。

## 数据与复现范围

新数据必须审核；旧实验与标签审计保存在研究档案，此介绍版不重复讲历史失败过程。方法复现不等于逐位重建旧私有adapter；原始业务日志和权重不随公开包分发。公开源码、数据合同、示例、计划与标量结果即可帮助开发者在自己的数据上复现流程。

`reviewed-example.jsonl`是三行合成格式示例，只用于本地校验；训练脚本明确拒绝把它当真实能力数据执行GPU训练。2026-10-18在新L40服务器完成11项CPU合同与协议验收，详见[实际验收记录](../research/decision-skills-l40-20261018/README.md)。现有GPU任务持续运行，本次没有新增GPU训练、真实模型推理或生产部署。训练计划同时校验CE与RLCD对应worker源码的生成与语法，并记录SHA。


各轮实验为什么这样设计、9B分类66/87→78/87的意义，见[实验主线与分类收益解读](Jev实验主线与9B分类收益解读_20261018.md)。
