# 光束视觉与交互改版

后续首页、身份与任务复用调整见 [最新设计说明](IDENTITY_AND_REUSE.md)。首页现已删除底部工作流预览。

使用项目根目录的 `logo.png`，原样复制到公共资源，作为侧栏、登录页和网站图标。新增 `public/aurora.css` 和 `public/motion-ui.js`，保留现有分析、账户、审核和评分接口。

- 配色：浅蓝背景、深蓝正文、亮蓝主要操作；紫色用于跑分卡片、青色用于投稿卡片，错误和待确认状态保留各自语义颜色。
- 主标题大字号、粗体、紧凑字距；副标题提高字号、保持正常字重。导航为不同功能使用独立图标。
- 左右光束各占 60% 屏宽、80% 屏高，以顶部左右角为旋转原点，分别旋转 20°、−20°；径向渐变从 75% 透明度的 `#a0cdff` 到 40% 透明度的 `#4687eb`，85% 处透明，并施加高斯模糊。主体与侧栏采用透明或半透明表面，背景不被整块底色覆盖。
- 内容以淡入、上移和短间隔依次进入；首次内容进场完成约 0.5 秒后光束淡入。定时刷新不重复播放页面进场动画。
- 工作台默认保持简洁，输入框位于中间偏下；展开选项后输入区上移，选项在表单内依次进入，避免遮挡其他功能。
- 底部展示分析流程与当前账号的最近业务任务摘要，无任务时显示等待状态。展示区支持鼠标 3D Tilt；键盘方向键也可倾斜，Escape 复位。悬停和聚焦期间暂停界面自动重绘。
- 个人空间改为三个主卡片，点击或键盘激活后切换对应列表 Tab，同时更新地址 `#/personal/logs`、`#/personal/runs`、`#/personal/skills`，支持直接访问和刷新。
- 窄屏调整为图标侧栏、纵向任务卡片和两列流程；尊重系统减少动态效果设置。

验证：浏览器检查桌面和窄屏布局、卡片跳转、刷新后的 Tab、选项展开、键盘 Tilt；原有 22 项回归测试通过。预览保存在 `docs/previews/aurora-workbench.jpg` 和 `docs/previews/aurora-personal.jpg`。
